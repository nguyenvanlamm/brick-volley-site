# Brick Volley — website

Static landing page and privacy policy for the Brick Volley game, served by
GitHub Pages from the root of `main`.

- `index.html` — landing page
- `privacy.html` — privacy policy (App Store / Google Play privacy URL)
- `style.css`, `assets/` — styles, screenshots, logo, self-hosted OFL fonts

No build step: edit the files and push. Split from `docs/` of the game repo
(`nguyenvanlamm/brick-volley`, branch `landing-page`).
